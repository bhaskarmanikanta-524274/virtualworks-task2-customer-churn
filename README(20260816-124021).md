# VirtualWorks Task 2 — Customer Churn Analysis

## Objective
Analyze a fictional laptop-repair customer base to identify behavioral patterns associated with churn and develop a leakage-safe machine-learning model.

## Dataset
A synthetic dataset of 1,200 fictional customers was created for this task because the tutorial video does not provide a downloadable dataset.

Features include tenure, repair frequency, support contacts, days since last service, satisfaction, response time, annual spend, plan, warranty status, discount usage, city and device brand.

## Key results
- Overall churn rate: **15.75%**
- Model accuracy: **68.67%**
- Precision: **28.83%**
- Recall: **68.09%**
- ROC-AUC: **0.744**
- Highest-churn plan: **Basic (16.92%)**

## Main behavioral findings
The analysis is designed to surface higher churn risk among customers with:
- longer gaps since their last service,
- lower satisfaction,
- more support contacts,
- slower response times,
- shorter tenure,
- and weaker plan/value signals.

These are associations in the synthetic dataset, not causal claims.

## Machine-learning approach
A Logistic Regression classifier was trained using a preprocessing pipeline. Numerical variables use median imputation and scaling; categorical variables use most-frequent imputation and one-hot encoding. The target and customer ID are excluded from the feature matrix.

The preprocessing pipeline is fit only on the training data, helping prevent data leakage.

## Retention recommendations
1. Trigger proactive service reminders for customers with increasing inactivity.
2. Prioritize low-satisfaction customers for support follow-up.
3. Investigate repeated support contacts and slow response times.
4. Use targeted retention offers instead of broad discounts.
5. Track precision and recall when deciding how many customers to target.
